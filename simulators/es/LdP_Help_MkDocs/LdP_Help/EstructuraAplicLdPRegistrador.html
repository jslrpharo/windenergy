    Sinópticos Registradores (StripRecorders)¶

    El intérprete de LdP incluye la posibilidad crear cualquier número de sinópticos tipo "Registrador", en los que se presenta la evolución de un conjunto de señales. La especificación de la representación se hace asociando el Registrador a un "Panel predefinido". Estos sinópticos están consituidos por:

    • Un Registro de base de tiempos que va desplazandose hacia la izquierda, conforme va transcurriendo el tiempo.

    • oLa evolución de una o más señales.

    • oUn eje vertical a la derecha, rotulado de acuerdo con el rango de valores de las señales. Puede ser lineal o logarítmico.

    • oLineas horizontales (marcas) correspondientes a determinados valores

      Las señales de un Registro deben ser del mismo tipo "analógicas" o "digitales". Cada señal puede tener un color asociado diferente.

      • El botón "Paneles predefinidos" presenta el conjunto de Paneles predefinidos para el Simulador que se está ejecutando.
