Exportación de los datos a Excel

Estructura de las aplicaciones LdP ›› Registro de valores de las Señales (datalogging) ››

La aplicación de escritorio SQLiteAdministrator (http://sqliteadmin.orbmu2k.de/)  dispone de una opción para exportar los datos de fichero SQlite a Excel.


El plugin "SQlite Manager" de Firefox también permite exportar el resultado de una consulta en a un fichero CSV (Valores Separados por Comas).

Estos ficheros pueden ser importados a libros Excel. Las ultimas versiones de Excel incluyen un formato que recoge bien el formato fecha con resolución de milisegundos. Ver la siguiente figura para  observar la traducción de la columna "Date" (la "A") a la traducida con la forma que se indica (columna "B") que está siendo representada con el formato de celda "dd/mm/aaaa h:mm:ss,000".
