Una aplicación LdP (Simulador) viene definida por una descripción en un fichero de configuración, en el cual:

•Se declaran cada uno de los componentes que se utilizan en el Simulador.

•Se declaran las conexiones entre las señaels de salida y entrada de cada uno de los componentes.

•Se definen elementos auxiliares: valores de parámetros, de ayuda, definición de configuraciones de Registradores gráficos, etc.

Synoptics

Este elemento puede contener uno o más elementos tipo "Synoptic" (Sinóptico). Estos elementos hacen referencia a DLLs desarrolladas específicamente usando indicadores gráficos. Constituyen la interfaz de usuario.

Connections

Este elemento contiene elementos tipo “InternalConnection”. Estos elementos contienen una "señal de salida" y una o varias "señal de entrada".

Parameters

StripRecorders

(Registradores) Este elemento contiene un conjunto de elementos tipo "Panel", cada uno de los cuales define el contenido y formato de "Recorder"s (Registro), a través de los que se definen el conjunto de señales que se presentan y la forma de la representación.

Elemento que contiene ninguno, uno o más elementos tipo "Function". Cada uno de estos elementos implementa una "formula":  cada formula tiene asociada una señal de salida y un conjunto de señales de entrada correspondientes a las variables que utiliza.
