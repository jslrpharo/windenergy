La estructura de las bases de datos usados para registrar las evoluciones de las señales de una simulación es la siguiente:

•Están contenidas en un solo fichero creado con el motor de bases de datos SQLite 3.6.

•Tiene una tabla por cada señal, ya sea de "salida" o de "entrada".

•Cada tabla contiene dos campos que dependen del tipo de señal (analógica o digital). Uno de estos campos ("Date") es común. Ver los siguientes detalles:
