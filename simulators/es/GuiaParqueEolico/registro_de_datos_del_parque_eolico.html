Registro de datos del Parque Eolico

Datos en un Parque Eólico

Los datos recibidos por el SCADA son almacenados en una base de datos o en ficheros secuenciales con indicación de la fecha.

En un Parque Eólico las fuentes de datos del SCADA son:

  • De cada uno de los aerogeneradores :
    • Variables ambientales (viento, dirección del viento, temperatura ambiental
    • Variables eléctricas: potencia activa producida, factor de potencia.
    • Incidencias reportadas por el Controlador
  • De la Torre Meteorológica:
    • Temperatura ambiente.
    • Humedad ambiente
    • Presión atmosférica.
    • Viento (a dos alturas)
    • Dirección del viento
  • De la Subestación eléctrica:
    • Medida oficial de la potencia activa producida y del factor de potencia.
    • Incidencias de operación de la Subestación.

Datos recogidos en el Simulador

En el Simulador,  cualquier variación en cualquiera de las señales es registrada. Este registro se hace en memoria. Cuando se sale del Simulador, el programa pregunta si quiere salvar los datos en memoria en una base de datos. Si la respuesta es positiva, se crea una base de datos tipo SQLite, consistente en un fichero que se crea en el subdirectorio "C:\WFS_Datalog". Debajo de este directorio se crea un directorio por cada tipo de Simulador. Debajo de cada uno de estos subdirectorios "de tipo de Simulador" se crea una base de datos cuyo nombre corresponde con el instante en que se ejecutó el Simulador. Por ejemplo: el fichero 
'C:\WFS_Datalog\Simulador de Parque Eolico\22-02-05-13-40-21.sqlite' corresponde al registro de la sesión del "Simulador de Parque Eolico" que comenzó el "(20)23-02-05-13-40-21"

La estructura de estas bases de datos se describe en detalle en el tutorial. Por cada "señal interna" en el Simulador (ver  el "Registro de Datos"), la base de datos creada contiene una tabla con dos campo "Date" y "Value". En el caso de señales analógicas el segundo campo se llama "ValueA", y "ValueD" si es digital. Estas bases de datos pueden son accesibles mediante varios programas "open-source" (ejemplos: "DB Browser for SQLite", "SQLiteBrowser", etc.). En general, estos programas ofrecen funcionalidades para presentar los datos de forma tabular, o en forma de plot. También para exportar sus datos a otros formatos, como hojas de cálculo, ficheros CSV, etc., para un análisis posterior.
